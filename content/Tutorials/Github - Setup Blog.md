1. Create a free account on Github. Follow the instructions on [[Github - Setup Personal Account]] article. 

2. Download the following [repository](https://github.com/dis-525/blog-template/releases/download/v.1/blog-main.zip). Unzip the folder. You'll need the files in later steps.
   
3. Create a new repository called <span style="color:#ffcc00;">blog</span>.

![[git-repo01.jpeg]]

![[git-repo02.jpeg]]

4. Once you hit the `Create Repository`, you see the following page. Click on `uploading an existing file` hyper link to upload the content.

![[git-repo03.jpeg]]

5. Drag & drop the downloaded files on <span style="color:#ffcc00;">Step 2</span>. Upload the folder content as follows. Wait for files to be uploaded completely. Then hit `Commit Changes` button.

![[git-repo04.jpeg]]

6. You'll see the following page. Hit `Settings` button.

![[git-repo05.jpeg]]

7. Navigate to left sidebar menu, and select **Pages** menu.

![[github13.jpeg]]

8. You will see the title **Branch**. There is a button called **None**, click on that button and select **main** and click **Save** button to proceed. This action will publish the repository as a web application to the public internet with a custom domain.
   
![[Github15.png]]

8. Now wait few minutes, Github handles all of the technical stuff to deploy your blog page. Return to repository page.

![[git-repo06.jpeg]]

9. Get the link to your blog

![[git-repo07.jpeg]]

![[git-repo08.jpeg]]

10. Click the link and view your blog. It should look like the following screen shot.

![[git-repo09.jpeg]]


## How to Update the Blog Content
Goto the Github repository page and click one of the blog posts as follows;

![[git-repo10.jpeg]]

Next, choose one of the posts.

![[git-repo11.jpeg]]

Hit the edit icon to start modifying the content.

![[git-repo12.jpeg]]

After you are done, click `Commit changes...` button to stage modifications.

![[git-repo13.jpeg]]

Apply modifications.

![[git-repo14.jpeg]]

Goto root folder and you will see an orange colored circle. It means that Github is working in the background to apply your changes and deploy your blog page. Wait a few minutes and refresh the page. You will see a green ✅ check mark that means your changes are being applied and the site is online.

![[git-repo15.jpeg]]


## How to Create a New Post?
Goto the Github repository page and click one of the blog posts as follows;

![[git-repo10.jpeg]]

Click the ▾ (down arrow) next to <span style="color:#ffcc00;">Add file</span> button and choose to upload your new blog post from your computer.

![[git-repo16.jpeg]]
