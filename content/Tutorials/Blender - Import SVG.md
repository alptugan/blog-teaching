## 1. Open Blender
Delete everything on the default scene; cube, camera, light...

## 2. Import SVG
Use `File > Import` menu to import your SVG file.

![[Blender - Import SVG01.jpg]]


## 3. Check Units
Goto right pane, choose `Scene` tab and check `Units`. Choose the appropriate `Length` value according to your project.

![[Blender - Import SVG02-1.jpg]]


## 4. Scale The Content
Hit `A` to select all layers, then `S` to scale the object.
