## Method 1: Context Menu
1. Right click on the video part
2. Choose `Change Clip Speed`
![[Davinci-Video-Speed-01.jpeg|-center|500]]


Set the speed of the video playback as follow;
1. `Speed` section adjusts the playback speed. E.g., `100%` actual speed. If you set it `200%`, the video playback becomes 2x speed.
2. Enable `Ripple Timeline`
3. Keyframes section set to `Maintain Timing`
4. Hit `Change` to apply speed adjustments.

![[Davinci-Video-Speed-01-1.jpeg|-center|500]]

## Method 2: Inspector Menu
You can use the inspector menu to adjust speed on the fly. It is much efficient and faster than the previous method. 
1. Goto `Inspector` pane on top-right corner of the application window.
2. Scroll down the content and find `Speed` settings section.
3. Adjust the speed using the UI dial.

![[Davinci-Video-Speed-02.jpeg|-center|500]]
