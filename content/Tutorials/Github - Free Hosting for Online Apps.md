This tutorial is a part of COD207/208 Creative Coding courses. It demonstrates:
1. Setup a free Github account.

5. Publishing to the internet and make it available to public.
## What is Github?
It provides a space for you to build a website that you can use for highlighting your Github projects, your web-based applications, or just yourself!
