1. Run the following command
`sudo nano /private/etc/motd`

2. Paste your desired message or figlet design via tools like the [link](https://www.asciiart.eu/text-to-ascii-art)

3. Save with `Ktrl + o`. Hit `y` to save.

4. Restart Terminal app.
