This tutorial is connected to [[Blender - 3D Print]], which presents how to create 3D prints using Blender.

Goto Edit>Preferences
![[blender-addon01.png]]

Then click on Get Extensions tab. Hit Install "3D Print Toolbox"
![[blender-addon02.png]]

Then, make sure that it is selected on Add-ons tab.
![[blender-addon03.png]]
