## Productivity & Devs
[Crontab.guru - The cron schedule expression generator](https://crontab.guru/#*/60_10-22/3_*_*_*) helps me to validate `crontab` scheduling format.

[Cron Visualizer](https://cron-visualizer.vercel.app/) allows visualization of cron jobs in graphical representation. Vertical axis represents days, horizontal axis represents time.

[Link Shortener free](https://shorten.ly/) An open source link shortener.

[DownGit](https://downgit.github.io/#/home) Copy the link of a GitHub folder inside a specific repo and download the specific folder. It helps you to avoid downloading entire project folder.

[Git Diagram](https://gitdiagram.com/) Scans the provided Github repository and generates block diagram.
