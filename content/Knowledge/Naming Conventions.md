There are four naming conventions in programming. We will focus on two following fundamental ones while using Javascript.

## camelCase
*camelCase* starts with a <font color="#00b0f0">lowercase</font> letter. Every new word starts with a <font color="#00b0f0">capital letter</font>. Commonly used in JavaScript, Java, C# and many other high-level programming languages. Review the following examples.

```js
//method declaration
void sendEmail()

//variable declaration
var  totalAmount;
```

## PascalCase
Every word starts with a <font color="#00b0f0">capital letter</font>, including the first letter. PascalCase is very popular in C#, .NET, and Java programming languages.

```js
//method declaration
void SendEmail()

//variable declaration
var  TotalAmount;

```
