Design profession and creativity have a mutual relationship. The practice during the process of design can be tedious because of time consuming compositional variations. A designer has to deal with renaming the files for a web site, deciding the appropriate size, type and color for the texts, rotating the objects in an accurate angle, or trying to position images in the document most of the time using the GUI. Of course, all these processes are inevitable for the design process. However a designer does not have to spend such a time to create variations while working on the project. Simple scripts can handle the repetitive tasks automatically and allows the designer to focus on the creative process for the project. 

Actually several image editing applications allows users to create automated actions and scripting support. For example Adobe Illustrator has had both of them since 2008 (ref1). The difference between “Actions” and “Script” support is; “Actions” execute the specific GUI functions determined by the user in  sequence and are not capable of responding to input data. It is not possible to achieve a logical operation using “Actions” in each step (Figure 1). 
![[figure5.jpg]]
Figure 1. For example; The user can run an Action to draw a spiral and place text onto the path but cannot modify the font size one by one. To do that one needs to select each character and adjust their size respectively.

However a “Script” can receive an input data and respond dynamically through the design process (Figure 2). 
![[figure6.jpg]]
Figure 2. The user can generate the spiral, then asks for input data to adjust the maximum and minimum font size for the text that will be placed onto the path of the spiral.
 
ref: [Page 9](zotero://open-pdf/library/items/SWUVEQ6W?page=9&annotation=69NLTT5G)
Scripts are a set of computational instructions which tell Illustrator to carry out one or several tasks via programming paradigms. The scope of the commands can encapsulate the whole document or a specific visual entity on the document. A designer or an artist must have fundamental programming concepts to enhance her workflow and avoid time consuming tasks during the creation process. If so one   can focus on the creative aspects rather than dealing with tedious repetitive tasks.
